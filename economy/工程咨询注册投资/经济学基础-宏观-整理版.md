# 宏观经济学基础

## 〇、这张地图怎么读

宏观经济看什么？一句话：**四大目标，三要素**。

| 宏观经济四大目标 | 运行衡量三要素 |
|---|---|
| 经济增长 | 产出（GDP） |
| 物价稳定 | 就业（失业率） |
| 充分就业 | 价格（CPI / PPI） |
| 国际收支平衡 | |

整章的骨架沿着三要素走：先看**产出怎么算**（GDP 与 GNI），再看**就业怎么分**（失业类型与充分就业），再看**价格怎么动**（通胀与指数），然后是**供需怎么决定均衡**（AD-AS），最后是**政策怎么调**（货币与财政）、**长期怎么增长**（增长核算）与**对外怎么平衡**（国际收支与汇率）。

## 一、GDP：产出怎么算

**GDP（国内生产总值）**：一个国家（地区）所有**常驻单位**在一定时期内生产活动的**最终成果**。

关键词是「**最终**」：中间产品（比如造汽车用的钢材）不计入，只算最终成果——这就是「消除各环节重复计算」的直觉。

### 三种核算方法

- **生产法**：增加值 = 总产出 − 中间投入（从生产环节算，消除重复计算）
- **收入法**：增加值 = 劳动者报酬 + 生产税净额 + 固定资产折旧 + 营业盈余（从收入形态算；GDP 为各行业增加值之和）
- **支出法**：GDP = 最终消费支出 + 资本形成总额 + 净出口（从最终使用算）

理论上三种方法结果相等（**三方等值**），实际统计中有误差。

### GDP 的三种形态

| 形态 | 用什么价格 | 用途 |
|---|---|---|
| 名义 GDP | 当期市场价格 | 反映当期名义规模 |
| 实际 GDP | 固定价格（不变价） | 监测真实增长 |
| 潜在 GDP | —（充分就业下的最大产出） | 长期趋势基准，表现为缓慢增长 |

$$GNI = GDP + \text{来自国外的要素收入} - \text{向国外的要素支付} = GDP + \text{国外净要素收入}$$

### 收入衡量指标链（从 GDP 到个人可支配收入）

- 国内生产净值 NDP = GDP − 固定资产折旧
- 国民收入 NI = NDP − 企业间接税（形式：工资、利息、租金、利润）
- 个人收入 PI = NI − 公司未分配利润 − 社会保险税 − 净利息 + 红利 + 政府向个人支付 + 个人利息
- 个人可支配收入 DPI = PI − 个人税收

## 三、就业与失业

产出与就业**同向**：产出水平越高，就业水平越高——所以充分就业是重要宏观指标。

### 失业的五种类型

| 类型 | 成因 |
|---|---|
| 摩擦失业 | 人群迁移、岗位变动过程中的暂时失业 |
| 结构失业 | 劳动力供需不匹配（人与技术/岗位结构不匹配） |
| 周期失业 | 总支出与产出下降（衰退期），又称需求不足失业 |
| 自愿失业 | 不满意工资或劳动环境而不就业 |
| 非自愿失业 | 愿意工作但无工可打 |

## 四、价格：通胀与指数

**通胀**：总物价水平普遍上升，货币贬值；反之为**通缩**。

### 按程度分类

| 类型 | 年涨幅 |
|---|---|
| 温和（爬行）通胀 | < 10% |
| 严重通胀 | 10% ~ 100% |
| 恶性通胀 | > 100% |

### 按成因分类

- **需求拉动型**：需求过量、货币过多而商品有限
- **成本推动型**：供给成本提高
- **供求混合推动型**：需求拉动 + 成本推动
- **结构性**：个别关键商品供求失调、经济部门发展失衡

### 价格变动的三个衡量指标

| 指标 | 度量对象 | 频率 |
|---|---|---|
| CPI 消费价格指数 | 一组消费品价格 | 月度 |
| PPI 生产价格指数 | 农工商三产业价格（一般为工业出厂价） | 月度 |
| GDP 平减指数 | 名义 GDP / 实际 GDP，整体物价走向 | 宏观测度 |

## 五、经济周期与 PMI

- 理想状态：GDP 缓慢增长 + CPI 缓慢增长
- 经济周期：扩张与衰退交替，周期约 2~10 年
- 长期增长趋势 = 潜在 GDP 的变动趋势
- 周期波动用**产出缺口**（实际 GDP 与长期趋势的差距）衡量
- 奥肯定律：产出缺口与失业率同向（美国经验约 2:1）

### 三种经济状态对照（重点）

| 经济状态 | 失业构成 vs 自然失业率 | 价格表现 |
|---|---|---|
| 实际 < 潜在产出 | 摩擦+结构+周期失业 > 自然失业率 | 通缩 |
| 实际 = 潜在产出 | = 自然失业率 | 价格上涨加快 |
| 实际 > 潜在产出 | < 自然失业率 | 通胀（产出受限，价格上调） |

### PMI 采购经理指数

- 月度报告，覆盖制造业与非制造业
- **先行指数**：预警预测、预测拐点
- 50% 为分水岭：PMI < 50% 经济收缩；PMI > 50% 经济扩张

## 六、总需求与总供给

**总需求 AD**：所有实体在各自价格水平上愿意购买的总量，与物价**反向**。

构成：消费 C（可支配收入与预期决定）、投资 I（建筑、设备、库存，受预期影响）、政府开支 G、净出口 NX（受国内外水平、价格、汇率影响）。

- 政策变量：货币供给、贷款条件、政府开支
- 外生变量：国外产出、净出口、资产价值、技术进步

**总供给 AS**：所有实体愿意卖出的总量，与物价**同向**。决定因素：潜在产出（基本因素）+ 投入、技术、效率。

总供需共同决定价格与均衡产出。**实际均衡产出未必等于充分就业产出——宏观政策的目标就是把两者拉平。**

## 七、宏观政策：目标与工具

四大目标：充分就业、经济增长、价格稳定、国际收支平衡。

工具的核心思想：**逆周期调整**——扩张工具在需求不足时刺激，紧缩工具在需求过热时降温。

### 货币政策（央行）

目标：币值稳定 + 促进经济增长。

- 宽松：降低贴现率、降低准备金率、扩大货币供给、放宽贷款条件
- 紧缩：出售政府债券等

对贸易平衡的影响：大量逆差时 → 宽松货币政策 → 低利率 → 本币贬值 → 出口增加、进口下降。

### 财政政策

工具：税收、补贴、赤字、国债、转移支付。

- **酌情（相机抉择）**：扩张期减税增开支；紧缩期加税减开支
- **非酌情（自动稳定器）**：累进税制、转移支付自动随经济波动调节

## 八、经济增长：长期怎么涨

- 潜在 GDP / GNI 的增长代表生活水平提高的速度
- 指标：GDP、人均 GDP、劳动生产率（GDP / 从业人数）、全要素生产率 TFP

### 经济增长四要素

人力资源、自然资源、资本、技术。

### 增长源泉与核算

源泉：劳动 L、资本 K、技术 TFP（土地视为常数）。

$$Q = \alpha \cdot L + (1-\alpha) \cdot K + TFP$$

其中 $\alpha$ 为劳动的贡献权重。**技术进步是持续增长最根本的源泉。**

促进长期增长的政策：人力资源培训、公共教育与研究、知识与产权保护、增加国民储蓄与投资（长期总供给曲线右移）。

## 九、国际收支、贸易与汇率

- **国际收支**：进出口贸易、投融资往来、对外债权债务
  - 流量统计：特定时期（货物服务进出、投资）
  - 存量统计：特定时点（国际投资头寸）
- **国际贸易**：基础是国际分工与**比较优势**——进口自己生产成本较高的商品
- 自由贸易 vs 保护贸易：进口限制（关税、反倾销、配额、许可、技术/卫生检验）、出口激励（补贴）
- **国际资本流动**：
  - 长期（>1 年）：直接投资、国际证券、国际贷款
  - 短期（<1 年）：保值、金融、贸易、投机
  - 直接投资获得企业**实际控制权**；证券投资只获得利息红利收益权
- **汇率制度**：固定汇率（可调整钉住、有管理的浮动）、浮动汇率

### 不可能三角（重点）

- 固定汇率 + 资本自由流动 → **货币政策**受限
- 浮动汇率 + 资本自由流动 → **财政政策**受限
